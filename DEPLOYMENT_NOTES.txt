STATIK deployment notes

Backend runs on Railway from statik-backend.
Frontend runs on Netlify from statik-frontend.
Public canonical domain is https://statik.au.

Backend Railway env:
PUBLIC_APP_URL=https://statik.au
FRONTEND_URL=https://statik.au
ALLOWED_ORIGINS=https://statik.au,https://www.statik.au
PUBLIC_SERVER_URL=https://YOUR-RAILWAY-BACKEND-DOMAIN
ADMIN_EMAIL=...
ADMIN_PASSWORD=...
UPLOAD_SIGNING_SECRET=...
ADMIN_DISPLAY_NAME=STATIK Admin
JWT_SECRET=...
MAX_UPLOAD_BYTES=41943040
STORAGE_PROVIDER=local
UPLOADS_DIR=/data/uploads

Mount a Railway volume at /data if using local uploads/JSON persistence.

Frontend Netlify env:
VITE_PUBLIC_APP_URL=https://statik.au
VITE_API_BASE_URL=https://YOUR-RAILWAY-BACKEND-DOMAIN
VITE_MAPBOX_TOKEN=...

Netlify SPA redirects keep /s/:slug on statik.au. The frontend resolves and tracks shortlinks by calling /api/links/resolve/:slug on the backend.

STATIK master corrective upgrade notes:
- Canonical public QR/share domain is PUBLIC_APP_URL / VITE_PUBLIC_APP_URL and should be https://statik.au.
- Backend/API/upload origin is PUBLIC_SERVER_URL / VITE_API_BASE_URL and should be the Railway backend domain.
- Google Maps location autocomplete uses VITE_GOOGLE_MAPS_API_KEY on Netlify.
- Local upload persistence requires DATA_DIR=/data and UPLOADS_DIR=/data/uploads with a Railway volume.
- Admin now includes Approval Bay, Messages, Media and Garage/Vehicles command pages.

STATIK master corrective v3 notes:
- Public share/QR URLs are canonicalized through PUBLIC_APP_URL=https://statik.au.
- Backend/API/upload URLs must use PUBLIC_SERVER_URL on Railway.
- Google Maps requires VITE_GOOGLE_MAPS_API_KEY on Netlify.
- Local uploads require Railway volume persistence at /data with UPLOADS_DIR=/data/uploads.
- AI Writer is admin-only and requires server-side AI_API_KEY; manual CMS still works without it.
